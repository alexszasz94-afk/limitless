---
name: new-video
description: Makes one finished, ready-to-post robe video (Snoopy or Princess) from an Instagram/TikTok link or a hook idea — hook start frames, hook clips, new B-roll with a new person and room, fixed connector/remote clips, trimming, edit with text and music. Run when the creator types "new video ...".
---
Work alone from start to finish. After EVERY image and EVERY clip run the skill `check` and repair alone before moving on; run it again on the final video before delivering. Keep the creator updated with one short line at each stage ("making the start frames…", "animating…", "editing…").

0. If `state/media.json` lacks the robe keys → run the `setup` skill first. Robe not given → ask "Snoopy or Princess?". Check `balance` (≥ 80 credits). Run `python3 engine/tools.py history` — this video must be DIFFERENT from the last 3 in hook concept, outfit, music cue and on-screen text (variety = the account doesn't look repetitive).
1. **Reference**: link → `python3 engine/tools.py download <url> output/_new/ref` and `sheet` it (1.5 fps); Read the sheet. Idea only → pick a proven concept in `HOOKS.md` that is NOT in the last 3 of `history` and adapt it. If people speak in the reference: WHAT they say → Higgsfield `video_analysis_create` on the uploaded hook part (free, the best: it says who speaks and the exact words; can sit in the queue 5–20 min, so start it FIRST and do the B-roll meanwhile) or `transcribe` on a computer; WHEN → `python3 engine/tools.py speech-times ref/reference.mp4 <hook length>` gives the second of each word. Write every word WITH its second. Make a 10 fps sheet of the hook part and write a timeline of every action with its second and speed (HOOKS.md step 3b) — you will paste it into the hook prompt. Decide: hook shots (1–4), each 1.5–3.5 s in the final video, total hook 3–7 s; the on-screen text (copy the reference wording, swap the product); whether it's a "whole clip" format (no B-roll, like "It's just a robe") or the standard hook + robe part.
2. **Name**: now that you know the video, pick a short folder name, e.g. `snoopy-castle`, `princess-hm`, rename `output/_new` to `output/<name>` and work there.
3. **Set**: `python3 engine/tools.py next-set` → character + room. LOOK at both (rule 1 in CLAUDE.md; bad → `reject` + `next-set`). For the B-roll make the head + shoulders crop of the character (`tools.py crop`, see PRODUCT.md). Upload the photo, the crop and the room (save ids in state/media.json). Pick an under-robe outfit (Christmas pajamas, cozy sweater set, college sweatshirt — always long pants) and describe the room from what you see in the photo. Do the **Room check** in CLAUDE.md (sofa / bed) now and choose the B-roll motion clip (princess: alternate motion / princess_motion_a, see PRODUCT.md).
4. **Start B-roll now** (it takes longest): exactly the B-roll recipe in `products/<robe>/PRODUCT.md`. (Skip for whole-clip formats.)
4b. **Hook = copy of the reference shot whenever possible** (HOOKS.md "Best way"): Kling video-edit on their own shot, with the action timeline + the spoken words with their seconds in the prompt. This is the approved method (motion and sound identical). Room photo has a table/object in the middle → first make the room without it (CLAUDE.md 7b). Use start frames (step 5–6) only when the shot needs something their video doesn't have.
5. **Start frames**: one per hook shot, recipe in `HOOKS.md`, all in one `generate_image_batch`. Download each with `python3 engine/tools.py fetch <url> output/<name>/start-<n>.jpg`, Read and check them (rules 6 in CLAUDE.md). Redo bad ones.
5b. **Hook sound**: if people speak in the reference, the words with their seconds go into the hook's own Kling prompt (HOOKS.md "Hook sound — cheapest first"), `"audio": true` in the edit. Only if that voice comes out wrong → Seedance fallback (slow, start it right away).
6. **Animate** every good start frame (one `generate_video_batch`), recipe in `HOOKS.md`. Fetch each to `output/<name>/hook-<n>.mp4`, `sheet` at 4 fps, `safe-end` + 10 fps sheet of the end, decide start/end of the usable part. Copied hook → `python3 engine/tools.py compare <reference> <hook> <from> <to> output/<name>/compare.jpg` around each key action and Read it: every action must be in the same column as the original (same second, same speed — e.g. the robe falls as slowly as theirs). Off → regenerate with the exact seconds and `slowly, same speed as the input video, never faster` in the prompt; the cut must be at the original's second (trim to it). Redo bad ones (max 3 tries). If only a short usable piece survives (e.g. 1.2 s), see "Short hook" in HOOKS.md.
7. **B-roll**: fetch to `output/<name>/broll.mp4`, `sheet` at 2.5 fps and check robe/hood/pouch/face. `cuts` → then `cozy` from the last cut + 0.15 (same in both PRODUCT.md files). If the creator asked for a special last shot (`cozy: ...`) → do "Custom cozy" in CLAUDE.md instead (start it right after the B-roll, it takes a few minutes).
7b. **Connector + remote in THIS video's room** (every video): upload `products/<robe>/fixed/connector.mp4` and `fixed/remote.mp4`, then `kling4_0` `video-edit` on each with the room photo as Image 1: `Edit the input video. Keep EXACTLY the same close-up shot, framing, hand(s), <connector / remote> and its lights, movements and timing. Change ONLY the softly blurred background behind the hands: it is now the room of Image 1, out of focus, soft bokeh. Nothing else changes. ... No text. Silent.` (duration 4 for connector, 3 for remote). Check the remote is unchanged and the lights go up; use these instead of the fixed clips.
8. **Edit**: write `output/<name>/edit.json` (format at the top of `engine/montage.py`) with the edit order from PRODUCT.md; hook texts end where the call-to-action starts (the lying shot), or one text for the whole video. Place texts with `"segs": [first, last]` (segment numbers), never by hand-computed seconds — montage prints the real cut times. Music from `products/<robe>/music/` (cue in PRODUCT.md; for Let It Go put the chorus on the reveal). Run `python3 engine/montage.py output/<name>/edit.json`. Whole-clip formats with ceiling-fan cuts: after montage run `python3 engine/tools.py fanwipe <final> <final-2> <cut times…>` and keep the wiped one as FINAL.
9. **Check the final**: `sheet` at 1 fps and `cuts`; text never over a face, text switches exactly on the cut, no leftover reference-photo flash, no black frames, ends cleanly. Fix and re-run if needed.
10. **Deliver** as described in CLAUDE.md (FINAL.mp4 + caption.txt + short summary). Then `python3 engine/tools.py log <name> robe=<robe> hook="<concept>" outfit="<outfit>" music="<song + cue>" text="<first on-screen text>" motion=<motion key> room=<room file> cozy="<cozy action or broll>"` so the next video is different.
