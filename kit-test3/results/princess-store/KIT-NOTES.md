## Kit problems / unclear / contradictions / my own decisions
1. **Connector fixed clip times are wrong (rule 9l / PRODUCT.md "0 -> 1.7").** connector-fabric-1.mp4 has hard cuts at 0.12 s (first 4 frames are ANOTHER shot - a different hand with pink nails) and 1.67 s (last frame jumps to a vertical close-up). Using 0 -> 1.7 puts two flash frames in every video (exactly what rule 9j forbids). I used **0.14 -> 1.64**. The kit should say that, or the file should be trimmed.
2. **Disk / montage temp:** montage.py writes its segment files to the system temp dir; with the shared disk full it crashed ("No space left on device", exit 228). Worked around with `TMPDIR=/dev/shm/... python3 engine/montage.py` (RAM disk) and by moving/deleting work files. audio3 + compare-audio also leave ~4-5 MB of demucs stems each (deleted by hand). The kit never says to clean stems / work files.
3. **Text rule contradiction:** CLAUDE.md rule 9 says suggest the reference's text "word for word, never rewrite"; new-video step 1 and HOOKS.md step 2 say "copy the reference wording, swap the product". Literal "Grinch-obsessed moms" would be wrong for a princess robe, so I swapped only the product word: "Princess-obsessed moms,\nRUN to Target😭💚" (kept the 💚, rule says same emojis - for a blue/yellow robe 💙👑 would fit better).
4. **Princess has no box / brand.** HOOKS/9g/9h demand "our box with OUR brand" but PRODUCT.md (princess) has no box ref and no brand name (Snoopy has snoopy_box). I invented the box myself: royal-blue box, gold border, robe photo, title "PRINCESS ROBE / HEATED HOODED ROBE" (gpt_image_2_5, robe front/back as refs).
