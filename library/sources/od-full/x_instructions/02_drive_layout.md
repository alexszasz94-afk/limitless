# 02 — Drive layout

The authoritative rules for names and folders are in `_tool/NAMING.md` (§1 product folders,
§2 product folder layout, §3 asset folder layout, §4 file names, §5 prompts.md). This page
is the map.

```
<drive root>/
  START_HERE.md, CLAUDE.md, AGENTS.md
  x_instructions/                 these docs
  keys.txt                        NOT included. Create it yourself (11_accounts_and_keys.md)

  <BRAND> - <PRODUCT>/            one per product, ALL CAPS, " - " between brand and product
    video_board.html              generated board (open in Chrome / Edge)
    content/
      video_<N>_assets/
        starting_frames/          v<N>_c<NN>_g<K>.png   generated frames
        clips/                    v<N>_c<NN>_g<K>.mp4   generated clips
        clips/upscaled/           same names, upscaled
        references/               v<N>_c<NN>_r<K>.png/.mp4   shot references
        prompts.md                every take: image prompt, video prompt, settings, result
      _board_thumbs/
        board_data.json           THE BOARD'S CONTENT (edit this, then rebuild)
        board_notes.txt           Notes panel file (starts empty)
        <mirror of content/>      small .webp thumbnails, generated by make_thumbs.py
      lost_takes.txt              takes whose files are gone for good
      stories/                    story / hero stills (optional)
      upscaled_videos/            (Swanlift) one upscale per finished video
    videos_to_post/               the finished, edited videos: video_<N>.mp4
    product_images/               packshots, box art, profile picture, Facebook cover
    competition/<account>/        competitor reels + data.md (views, hooks, CTAs)
    references/                   product-level references (rooms, product photos)

  _tool/                          NAMING.md + check_naming.py, make_thumbs.py,
                                  mark_lost.py, check_board.py
  x_assets/images/                board favicons / icons
  x_context/                      business.md, priorities.md, decisions.md (history)
  x_research/                     model prompting guides, upscaler research, Genjutsu
                                  research (genjutsu/ = 40 tutorial transcripts + index),
                                  dropshipping sourcing playbook
  x_systems/
    video_boards/                 board kit: README, SYSTEM, WORKFLOWS, template/, tools/
    product_finder/               board_data.json, product_board.html, links.txt,
                                  media/ (competitor reels + posters), raw/ (evidence)
    hooks/                        hooks_board.html, assets/, thumbs/, text_on_screen.txt
    distribution/                 posting portal (Next.js); its own README + CLAUDE.md
    social_tracker/               tracker (Next.js + scraper); its own README + CLAUDE.md
    customer_support/             kit/ (generic support-email system) + build_shared_card.py
    fulfillment/                  kit/ (generic supplier tracker) + supplier research reports
```

## Notes

- Inside a product folder everything is lowercase with underscores. The product folder
  name itself is the exception (ALL CAPS).
- `MERRYGLOWUSA - CHRISTMAS PROJECTOR` was renamed from `UBU - CHRISTMAS PROJECTOR`. Its
  text was rebranded, but the generated media still shows UBU box art.
- `SWANLIFT - POSTURE CORRECTOR BRA` was renamed from `WBW - POSTURE CORRECTOR BRA`. Its
  board key stays `wbw_posture_corrector_bra` on purpose (saved review marks depend on it).
- Never rename a product folder: the board, `board_data.json` (`"product"`) and every tool
  depend on the exact name.
- A new product = a new `BRAND - PRODUCT` folder, made with
  `x_systems/video_boards/tools/new_board.py` (see `x_systems/video_boards/WORKFLOWS.md` §1).
