# Platforma LIMITLESS: întâi ca a lor, apoi mai bună

(10 oct 2026, Szasz) Platforma trebuie să funcționeze ca sistemul din arhiva de 20 GB (`library/sources/od-full/x_systems/video_boards/SYSTEM.md`, `product_finder`, `hooks`), apoi să-l depășească: **agenții gândesc singuri ce să facă**. UI în engleză, accesibil vizual, futurist.

## Ce copiem de la ei
| Al lor | La noi |
|---|---|
| Product Finder: categorie → produs → variație → conturi, card cu video vertical, urmăritori, medie vizualizări, căutare | tab **Product finder**, cu videourile reale (fv/), click-to-play, un singur video pornit odată |
| Video Board: un rând (lane) pe video; grupuri Hook / B-roll; card pe cadru cu start frame, clip, status, Approve/Reject, sertar „Prompts” cu promptul exact + referințe în ordine | tab **Production** → video boards pe produs (de construit) |
| Hooks Board: hook-uri dovedite pe concepte, prompt exact, lista „ce schimbi / ce nu atingi”, jurnal de refolosiri | tab **Hooks** (de construit) |
| Notes panel care se salvează singur | panou de note (de construit) |
| Review N / Copy decisions | coada de decizii pentru Szasz |

## Unde suntem mai buni
1. **Agenții decid, omul aprobă doar excepțiile.** La ei omul aprobă fiecare cadru de două ori. La noi QA-ul automat (alt agent decât producătorul) verifică, regenerează de max. 3 ori și trimite la Szasz doar ce nu poate decide.
2. **Verdictul creierului pe fiecare produs**: cerere (media vizualizărilor), aglomerare (câți vânzători organici), ce urmează (test order). Strategul propune la cerere unghiuri noi, o variație și un hook.
3. **Bani, nu doar vizualizări**: $ / 1M vizualizări, cod de reducere pe cont și unghi, scor pe hook după vânzări.
4. **Totul legat**: produs → virale → producție → postare → cifre → reguli noi, într-o singură platformă, nu fișiere HTML separate.
5. **Un singur creier pe 10 produse**, cu buget de credite și priorități, nu un board pe produs deschis manual.
