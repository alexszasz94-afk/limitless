Robe Studio · setup

Ready in 5 minutes, all in your browser.

This setup is only for Claude Code on the web (claude.ai/code). Nothing gets installed on your computer.

Never done anything like this before? Perfect, this is written for you. You click through five steps once. After that you only chat with Claude, like texting a friend.

Claude Pro or MaxHiggsfield accountfree GitHub account

You don't edit anything. Ever.

No video editing, no files, no code, no settings to change later. You send a reel or an idea, Claude makes the whole video, checks it, and hands you the finished MP4. If you want something different, you just tell Claude in a normal sentence.

What Alex does

  • Prepares the whole Robe Studio kit: the robes, the rules, the clips, everything.
  • Sends you this page and a folder called robe-studio-upload with 5 files in it (the whole kit).
  • About once a week sends you a small update file with improvements.
  • Is there if something doesn't work.

What you do

  • Make 3 free/paid accounts if you don't have them: Claude (Pro), Higgsfield, GitHub.
  • Click through the 5 steps below, once.
  • After that: send Claude reels and ideas, and post the videos.

Two words you'll see:

GitHub is a free website that keeps your own online folder. In it lives the Robe Studio kit and your finished videos. You never open the files yourself.

Claude Code is a chat with Claude at claude.ai/code that can work inside that folder. That's where you talk to Claude.

The pictures below are simplified drawings of the real screens: the red numbers show where to click, in order. Your screen may look a little different, but the button names are the same.

0 of 5 done
  1. 1

    Put the kit in your own GitHub folder

    First download the robe-studio-upload folder Alex sent you to your computer. Inside are 5 files: CLAUDE.md and 4 pieces called robe-studio.zip.part-aa … -ad. Don't open or unzip them.

    No GitHub account yet? Go to github.com, click Sign up and make a free account (email + password).

    On GitHub, click the + at the top right:

    +→New repository

    In Repository name write robe-studio, choose Private (only you can see it), click Create repository.

    On the next page click the blue link uploading an existing file. Open the robe-studio-upload folder on your computer, select all 5 files inside it (Ctrl+A on Windows, Cmd+A on Mac) and drag the files into the page, not the folder itself. Wait until all 5 are listed, then click Commit changes.

    That's your own online folder with the kit in it. You never need to open it. Claude unpacks it by itself the first time you say hi.

  2. 2

    Connect Higgsfield

    Higgsfield is the website that makes the images and videos. Claude uses your account there.

    Open claude.ai/customize/connectors (log in to Claude if asked). Find Higgsfield in the list:

    Higgsfield→Connect→log in with your Higgsfield account→Allow

    When it says "Connected", this step is done.

  3. 3

    Open Claude Code

    Go to claude.ai/code.

    The first time it asks to connect GitHub. Click Connect GitHub, log in, and when GitHub asks which folders Claude may use, choose robe-studio and click Install / Save.

    Back on claude.ai/code, choose robe-studio from the list. A chat box opens.

  4. 4

    Let it reach Instagram and TikTok

    Next to the chat box there's a small cloud icon with a name (usually "Default"). Click it, then the little pencil / Edit.

    Find Network access. This decides which websites Claude may open. Pick one of the two options, whichever you prefer:

    Option A · Full easiest

    Network access→Full→Save

    Claude can open any website. One click, nothing else to do.

    Option B · Only the sites it needs stricter

    Network access→Custom (or Limited)

    Leave Allow package managers ticked. In the box Allowed domains paste this whole list, then Save:

    *.higgsfield.ai
*.cloudfront.net
*.instagram.com
*.cdninstagram.com
*.fbcdn.net
*.facebook.com
*.tiktok.com
*.tiktokcdn.com
*.tiktokv.com
*.pinterest.com
*.pinimg.com
*.youtube.com
*.googlevideo.com
*.ytimg.com
huggingface.co
*.huggingface.co
*.hf.co

    Claude can then open only Higgsfield, Instagram, TikTok, Facebook, Pinterest, YouTube and the speech-to-text site. If one day Claude says a site was blocked, it tells you which line to add.

    Either way, you do this once and never again.

  5. 5

    Say hi

    Write in the chat:

    Hi, set me up

    Press Enter and wait a few minutes. Claude prepares everything by itself and writes back when it's ready. If it asks you something, just answer in normal words. If a window pops up asking to allow something, click Allow / Yes.

About once a week

Updates from Alex

When Alex sends you a file like robe-studio-update-2026-11-02.zip, open a chat in claude.ai/code, drag the file into the chat and write:

Here is the new update from Alex

Claude installs it and tells you in two lines what's new. Your videos and history stay as they are.

Every day after that

Just talk to Claude

No commands to learn. Write like you'd text a friend who edits videos for you:

Make this one with the princess robe: https://www.instagram.com/reel/…
I have my own idea: she opens the front door and her mom holds a giant gift box.
The text is too big.

Want a specific song? Download it as an MP3 and drag it into the chat (or click the paperclip and choose it), then say "use this song". Claude finds the best part of it and puts it in the video perfectly, with the chorus on the big moment.

Claude asks you one question (which cozy ending you want), then makes the video, checks every frame and gives you the finished MP4 and a caption to copy. You don't cut, edit or fix anything. To save the video: click it in the chat and download it. (It's also kept in your GitHub folder, under output.)

Your part is the ideas. Copy reels that work, and every two or three videos try a hook of your own.

If something goes wrong

  • Claude says Higgsfield isn't connected: redo step 2, then start a new chat.
  • Claude says a download was blocked: check step 4 (with Option B, add the site Claude names to the list), then start a new chat.
  • Still stuck: write to Alex.
  • Anything else: ask "what went wrong?" and Claude explains and fixes it.
